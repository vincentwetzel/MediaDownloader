# LzyDownloader v1.2.48

This release adds configurable Local API ports, shared runtime coordination,
more accurate transfer progress, and clearer download feedback.

- Configure the localhost Local API port from Advanced Settings, with atomic
  discovery for the Discord bridge and browser companion.
- Share one queue owner across GUI, server, headless, and background launches.
- Improve segmented aria2 progress accuracy by relying on native transfer
  output instead of temporary `.part`-file size polling.
- Add compact media-type icons to active downloads and preserve playlist audio
  track numbers in embedded metadata.
- Refresh completed-download thumbnails asynchronously in Download History.
- Deploy MinGW runtime DLLs beside Windows targets and refresh extractor
  catalogs for the release.

Release assets:

- Windows installer: `LzyDownloader-Setup-1.2.48.exe`
- Linux AppImage: `LzyDownloader-1.2.48-x86_64.AppImage`
- Intel macOS DMG: `LzyDownloader-1.2.48-macos-x86_64.dmg`
- Apple Silicon DMG: `LzyDownloader-1.2.48-macos-arm64.dmg`
