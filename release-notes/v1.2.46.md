# LzyDownloader v1.2.46

This patch release improves audio artwork handling, playlist expansion, and
release-test diagnostics.

- Preserve landscape audio artwork while removing only high-confidence borders
  from centered square artwork.
- Expand search-shaped URLs into separate queue items and keep ordinary URL
  fallback downloads bounded after transient playlist-probe failures.
- Keep valid Opus, Ogg, AAC, and WAV downloads usable when attached artwork is
  unsupported or unavailable.
- Improve headless CI diagnostics by rerunning failed tests serially with
  verbose output and direct QtTest invocation.

Release assets:

- Windows installer: `LzyDownloader-Setup-1.2.46.exe`
- Linux AppImage: `LzyDownloader-1.2.46-x86_64.AppImage`
- Intel macOS DMG: `LzyDownloader-1.2.46-macos-x86_64.dmg`
- Apple Silicon DMG: `LzyDownloader-1.2.46-macos-arm64.dmg`
